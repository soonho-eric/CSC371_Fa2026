1. **Temperature conversion**
   Ask the user for a temperature in Fahrenheit and convert it to Celsius using

   $$
   C = \frac{5}{9}(F-32).
   $$

2. **Rectangle calculations**
   Store the length and width of a rectangle in variables. Compute and print its area and perimeter.

3. **Even or odd**
   Ask the user for an integer and print whether the number is even or odd.

4. **Largest of three numbers**
   Given three numbers, use `if` statements to determine and print the largest one. Do not use `max()`.

5. **Sum from 1 to n**
   Ask the user for a positive integer `n`. Use a `for` loop to calculate

   $$
   1+2+\cdots+n.
   $$

   Compare your answer with the formula \(n(n+1)/2\).

6. **Count vowels**
   Given a string such as

   ```python
   text = "artificial intelligence"
   ```

   count how many characters are vowels.

7. **Working with a list**
   Given

   ```python
   data = [4, 7, 2, 9, 5, 11, 3]
   ```

   write code to:

   * print the first and last elements,
   * find the sum of the elements,
   * calculate the mean,
   * create a new list containing only values greater than 5.

8. **FizzBuzz**
   Print the integers from 1 through 30. For multiples of 3, print `"Fizz"` instead of the number. For multiples of 5, print `"Buzz"`. For multiples of both, print `"FizzBuzz"`.

9. **Write a function**
   Write a function

   ```python
   def distance(x1, y1, x2, y2):
   ```

   that returns the Euclidean distance between two points:

   $$
   d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}.
   $$

   Test it on several pairs of points.

10. **Simple data-analysis problem**
    Suppose these are exam scores:

    ```python
    scores = [72, 88, 91, 65, 79, 95, 84, 58, 90, 76]
    ```

    Write code that determines:

    * the mean score,
    * the highest and lowest scores,
    * how many students scored at least 80,
    * the percentage of students who scored at least 80.
